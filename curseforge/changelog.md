First release, for Hytale 0.7.1 with the game in Simplified Chinese.

- Item names with tone-marked pinyin: 铁手斧 (tiě shǒu fǔ).
- Item descriptions with pinyin above every word, lined up with the characters.
- Pinyin in in-game labels (benches, rarities, interaction hints), the menus and the loading screen.
- `/hanzi colors`: tone colours in the pinyin (off by default).
- `/hanzi english`: the official English name and description next to the Chinese (off by default).
- Settings are per player and saved.
- The JAR installs the fonts and menus with pinyin into Hytale itself the first time you open a singleplayer world with it, keeping a backup of the originals; restart Hytale once afterwards. `/hanzi restore` puts the originals back and `/hanzi install` reinstalls. On dedicated servers each player gets a one-time test line.
- Built from Hytale 0.7.1's own texts.
